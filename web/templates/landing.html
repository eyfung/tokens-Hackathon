🔥 The Problem

⏱️ Months Per Design

A single clinical trial design requires weeks of manual simulation work by scarce biostatisticians. Getting it wrong means starting over.

💰 $50-100M at Risk

A failed Phase III trial can cost $100M+. Poor trial design — wrong sample size, flawed eligibility criteria — is a leading cause of failure.

🏥 Excluded Teams

Small biotechs and academic researchers can't afford dedicated biostatisticians. Good trial design is a luxury, not a given.

⚡ The Agent

🔍 Searches Memory

Before running a single simulation, the agent queries Actian for similar past designs — diseases, endpoints, sample sizes, outcomes.

🧪 Simulates Patients

Using Pioneer and DeepMind, it generates thousands of virtual patient populations and evaluates statistical power.

👤 Escalates to You

If the design is underpowered, it opens a Band room, explains the risks, and suggests concrete fixes — then learns from your response.

Clone the repo, install dependencies, and launch the agent:

cd tokens-Hackathon
pip install -r requirements.txt
streamlit run web/app.py

No API keys required — runs fully offline with mock data.
Add your Pioneer / DeepMind / Band keys to config/partners.yaml for live inference.
