The problem

Months per design

A single clinical trial design requires weeks of manual simulation work by scarce biostatisticians. Getting it wrong means starting over.

Dollars at risk

A failed Phase III trial can cost $100M+. Poor trial design is a leading cause of failure.

Excluded teams

Small biotechs and academic researchers cannot afford dedicated biostatisticians. Good trial design is a luxury.

The agent

Searches memory

Before running a single simulation, the agent queries Actian for similar past designs — diseases, endpoints, sample sizes, outcomes.

Simulates patients

Using Pioneer and DeepMind, it generates thousands of virtual patient populations and evaluates statistical power.

Escalates to you

If the design is underpowered, it opens a Band room, explains the risks, and suggests concrete fixes.

Get started

Clone the repo, install dependencies, and launch the agent. No API keys required — runs fully offline with mock data.

cd tokens-Hackathon
pip install -r requirements.txt
streamlit run web/app.py

Add your Pioneer / DeepMind / Band keys to config/partners.yaml for live inference.
